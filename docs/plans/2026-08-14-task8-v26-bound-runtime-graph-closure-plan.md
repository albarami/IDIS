# Task 8 full-strict-v26 bound-runtime graph closure Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use `executing-plans` and
> `test-driven-development` to implement this plan task-by-task.

**Goal:** preserve the approved dashboard-root-equation-v3 semantics while
correcting the general identity/hash graph so every governed `$...` runtime
binding is retained atomically and classified as `BOUND_RUNTIME_INPUT`, then
return independent fixture, application-role census, and INACTIVE atomic
publication evidence.

**Architecture:** build v26 from frozen v21 plus the complete approved Task-8
delta set, never from void v22, v23, v24, or v25 bytes. The v25 equation-v3
semantic vector remains byte-identical after version/hash substitution. The
only new correction is evidence-structural: tokenization retains the `$`
marker long enough to distinguish three generic cases. An independently
derived governed producer reference remains an edge; an unresolved placeholder
inside a `RUNTIME_VALUE` preimage becomes one `BOUND_RUNTIME_INPUT` leaf; and a
contract-definition placeholder retains its separately derived authority.
Closed producer/source-shape admission prevents an injected producer from
capturing a bound placeholder. Candidate bytes remain in memory or an explicit
noncanonical `.local_reports` namespace until the atomic publisher creates the
fixture first and links the artifact last.

**Tech Stack:** Python 3.12, Pydantic 2.12.5, canonical JSON/SHA-256,
PostgreSQL/Alembic, psycopg2, pytest, Ruff, mypy.
